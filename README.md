# Netflix Data Analysis Using SQL

## Project Overview

This project focuses on analyzing the Netflix Movies and TV Shows dataset using SQL and MySQL 8.0.

The main objective is to explore Netflix content, identify trends, analyze movies and TV shows, and extract meaningful insights using SQL queries.

## Dataset Information

The dataset contains information about Netflix titles, including:

- Show ID
- Type (Movie / TV Show)
- Title
- Director
- Cast
- Country
- Date Added
- Release Year
- Rating
- Duration
- Listed In (Genre)
- Description

## Tools & Technologies

- MySQL 8.0
- MySQL Workbench
- SQL

## SQL Concepts Used

- SELECT and DISTINCT
- WHERE and LIKE
- ORDER BY and LIMIT
- GROUP BY and HAVING
- Aggregate Functions (COUNT)
- String Functions (TRIM, SUBSTRING_INDEX)
- Type Conversion (CAST)
- Date Functions (STR_TO_DATE, YEAR)
- CASE Statements
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions (ROW_NUMBER)

## Business Questions & SQL Analysis

This project answers 15 analytical questions:

1. Find the total number of Movies and TV Shows on Netflix.
2. Identify the top 5 countries producing Netflix content.
3. Retrieve movies and TV shows released in 2020.
4. Find all movies directed by Kirsten Johnson.
5. Identify the most common content ratings.
6. Find TV Shows with 5 or more seasons.
7. Find Indian movies belonging to the Comedies category.
8. Analyze the number of titles released each year.
9. Find the top 5 directors with the highest number of directed movies.
10. Identify the year Netflix added the highest amount of content.
11. Find the 5 oldest movies released in India.
12. Find documentaries released after 2015.
13. Identify the movie with the longest duration.
14. Find the latest released movie for each country.
15. Identify years in which more than 50 Indian movies were released.

## How to Run This Project

1. Clone this repository.
2. Open MySQL Workbench.
3. Create the database using the provided SQL script.
4. Import the Netflix dataset into MySQL.
5. Execute the SQL queries one by one.
6. Explore the results and insights.
